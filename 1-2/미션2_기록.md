# 미션 2 기록

- **사용한 AI 이름 / 주요 대화 캡처 파일명:** ChatGPT (GPT-6) / image.png
- **좁혀서 적은 한 문장:** 제목에 띄어쓰기가 있는 영화는 카드를 클릭해도 선택 테두리가 나타나지 않고, 끌어 놓아도 등급 칸으로 이동하지 않지만, 띄어쓰기가 없는 영화는 정상적으로 선택하고 이동할 수 있다.
- **좁히려고 해 본 것과 결과:**
  1. 원본 `영화_수정전.html`을 열고 '처음으로'를 눌러 초기화했다.
  2. 기본 영화 8개를 클릭 후 등급 선택, 끌어 놓기 방식으로 각각 확인했다. `기생충`, `인터스텔라`, `라라랜드`, `범죄도시`, `타이타닉`은 두 방식 모두 성공했다. 반면 `센과 치히로의 행방불명`, `어벤져스: 엔드게임`, `토이 스토리`는 두 방식 모두 실패했다. 특히 실패한 카드는 클릭해도 선택 테두리가 표시되지 않았다.
  3. 처음에는 새 영화 추가도 안 되는 것으로 생각했으나, 화면을 다시 확인한 결과 추가 기능은 정상 작동했다. **추가 실패와 이동 실패를 구분하여 관찰 내용을 바로잡았다.**
  4. 띄어쓰기 유무에 따라 결과가 달라지는지 확인하려고 `어바웃 타임`과 `괴물`을 직접 추가했다. 두 카드 모두 생성됐지만, 띄어쓰기가 있는 `어바웃 타임`은 선택 및 이동에 실패했고, 띄어쓰기가 없는 `괴물`은 정상적으로 선택 및 이동했다.
- **AI가 말한 원인과, 그 설명을 직접 확인한 결과:** AI는 영화 카드 생성 시 `data-id` 값을 따옴표 없이 HTML 문자열에 넣어 제목에 띄어쓰기가 있으면 식별값이 첫 번째 단어까지만 처리된다고 설명했다. 그러면 클릭하거나 끌어 놓을 때 해당 영화를 원래 목록에서 찾지 못해 이동하지 않는다. 기본 영화 8개와 추가한 `어바웃 타임`·`괴물`의 결과가 이 설명과 일치했다. 다만 브라우저 개발자 도구로 실제 `data-id` 값을 직접 확인하지는 않았고, **원본 코드 분석과 동작 비교를 통해 확인**했다.

| 파일명 | 고친 내용 | 다시 해 본 결과 |
|---|---|---|
| `영화_수정1.html` | 영화 카드 생성 코드에서 HTML 문자열에 `data-id`를 이어 붙이는 방식을 바꿔, 버튼 요소를 직접 만들고 `element.dataset.id = item.id`로 영화 식별값을 설정했다. 제목 표시도 `textContent`로 처리했다. 그 외 화면 디자인과 기능은 유지했다. | 수정 파일을 연 뒤 '처음으로'를 눌렀다. 기존에 이동하지 않았던 영화 3개와 새로 추가한 `어바웃 타임`의 이동을 확인했고, `괴물`과 원래 정상 작동하던 영화도 이동했다. 파일을 다시 열었을 때 배치가 유지되는지와 '처음으로' 초기화가 되는지도 확인했다. **수정 후 체크리스트 8개 항목 모두 정상 작동했다.** |

- **(선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:** 처음에는 '추가' 기능까지 고장 난 것으로 판단했지만 다시 확인해 보니 실제 오류는 카드 선택·이동에 있었다. 동료들은 증상을 어떻게 구분하고, AI의 원인 설명을 어떤 실험으로 검증했는지 비교해 보고 싶다.
