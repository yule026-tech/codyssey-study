# 민수 님께 드리는 영화 티어리스트 피드백

## 잘된 점

영화 카드를 선택한 뒤 등급을 누르는 방식과 직접 드래그하는 방식을 모두 사용해 보니 카드 이동이 정상 작동했습니다. 등급마다 색을 다르게 사용한 점도 알아보기 쉬웠습니다.

영화 추가와 '처음으로' 버튼도 정상 작동했습니다. 등급별 색상 구분과 상단의 분류 수 표시도 유용했습니다.

## 고치면 좋을 점

### 1. 영화 배치와 추가 목록 저장

- **본 것:** 영화를 등급 칸으로 옮긴 뒤 새로고침하니 분류 결과가 사라지고 처음 상태로 돌아왔습니다.
- **기준:** 기획서의 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.'
- **제안:** 영화를 추가하거나 등급을 옮길 때 상태를 브라우저 저장소에 저장하고, 다시 열면 저장된 목록과 등급을 불러오도록 수정하면 좋겠습니다. '처음으로'를 누를 때는 저장된 상태도 초기화하면 좋겠습니다.

### 2. 좁은 화면에서 오른쪽이 잘리는 문제

- **본 것:** 휴대폰으로 HTML을 열었더니 오른쪽이 잘리고 아래쪽 분류표도 제대로 보이지 않았습니다. HTML 코드에는 페이지 너비가 960px로 고정되어 있습니다.
- **기준:** 기획서의 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.'
- **제안:** 페이지에 고정된 960px 너비 대신 화면 너비에 따라 줄어드는 레이아웃을 적용하고, 좁은 화면에서는 입력창과 버튼도 줄바꿈되게 하면 좋겠습니다. 수정 후 실제 휴대폰과 좁은 브라우저 화면에서 다시 확인하면 좋겠습니다.

### 3. 빈 제목으로 영화가 추가되는 문제

- **본 것:** HTML 코드를 확인하니 제목이 비어 있는지 검사하지 않고 추가하도록 되어 있습니다. 빈 제목을 입력했을 때 빈 카드가 생기는지도 직접 재확인하면 좋겠습니다.
- **기준:** 기획서에 빈 제목 처리 조건은 없지만, 실제 사용 시 어떤 영화인지 알 수 없는 카드가 생겨 불편했습니다.
- **제안:** 제목이 비어 있거나 공백만 입력된 경우에는 카드를 만들지 않고 '영화 제목을 입력해 주세요'라는 안내를 보여 주면 좋겠습니다.

### 4. 아래쪽 영화 목록에서 위쪽 등급으로 이동하는 불편

- **본 것:** 미분류 영화 카드는 S·A·B·C 등급 칸 아래에 있어서 드래그 이동 거리가 길어질 수 있습니다. 다만 직접 테스트에서는 카드 이동 자체가 정상 작동했습니다.
- **기준:** 기획서 위반은 아니지만, 화면이 긴 경우 드래그로 이동하기가 불편할 수 있습니다.
- **제안:** 미분류 목록의 위치는 기획서대로 아래에 유지하되, '카드를 누른 뒤 원하는 등급 글자를 누르면 이동합니다'라는 안내를 더 눈에 띄게 표시하면 좋겠습니다.

전체적으로 기본적인 영화 분류와 초기화 기능은 잘 구현되어 있습니다. 특히 저장 기능과 좁은 화면 문제를 먼저 보완하면 기획서의 완성 기준에 더 가까워질 것 같습니다.
