AI로 글·그림·영상 만들어 나만의 광고 만들기

1. 미션 소개
새로운 서비스를 알릴 때는 어떤 서비스인지, 왜 써 볼 만한지를 짧은 시간 안에 전달해야 합니다. 생성 도구를 활용하면 글, 이미지, 영상, 목소리를 직접 만들 수 있지만, 각각의 결과물이 좋아도 메시지와 분위기가 어우러지지 않으면 하나의 광고로 전달되기 어렵습니다. 따라서 도구의 특성을 이해하고, 서비스에 맞는 소재를 골라 일관된 영상으로 완성하는 능력이 필요합니다.

이번 미션에서는 다음 단계에서 만들 서비스를 미리 구상하고, 그 서비스를 소개하는 10초 광고를 생성 도구로 제작합니다. 서비스 이름과 한 줄 소개, 톤앤매너를 정한 뒤 장면별 스토리보드를 기획합니다. 이를 바탕으로 텍스트, 이미지, 영상, 오디오를 생성하고 하나의 영상으로 통합합니다. 짧은 시간 안에 핵심을 전달할 수 있도록 무엇을 보여주고 무엇을 덜어낼지 판단하고, 그 이유도 기록합니다.

미션을 마치면 생성 도구별 강점과 한계를 자신의 결과물로 설명할 수 있습니다. 여기서 정한 서비스 이름과 톤앤매너, 카테고리별 프롬프트와 작업 기록은 다음 단계에서 서비스를 구현할 때 이어서 활용합니다. 전달할 메시지와 분위기를 먼저 정하고 소재를 고르는 방식은 발표 자료나 소셜 콘텐츠를 만들 때도 적용할 수 있습니다.

이 미션에서 다루는 것은 아래와 같습니다.

서비스 정체성 정의
장면별 스토리보드 기획
텍스트, 이미지, 영상, 오디오 생성 도구 비교
프롬프트 작성과 수정 기록
해상도, 화면 비율, 톤을 맞춘 영상 통합
서비스 이름과 특징을 기억하게 하는 마무리 장면 구성
작업 단위 기록
본격적인 실습에 앞서, AI에게 질문하며 관련 개념과 진행 방법을 미리 살펴볼 수 있습니다.

3. 과제 목표
이 과제를 마친 후, 학습자는 아래를 스스로 설명할 수 있어야 한다.

텍스트, 이미지, 비디오, 오디오 생성 도구의 강점과 약점을 구분할 수 있다.
기획 의도에 맞는 결과를 얻기 위해 프롬프트를 어떻게 설계하고 고쳤는지 설명할 수 있다.
같은 요구를 여러 도구로 시도한 결과를 비교하고 도구를 선택한 이유를 설명할 수 있다.
생성한 미디어를 해상도, 비율, 톤앤매너 관점에서 정리해 하나의 영상으로 통합한 기준을 설명할 수 있다.
다음 단계에서 만들 서비스에 정한 이름, 한 줄 소개, 톤앤매너가 광고에 어떻게 반영되었는지 설명할 수 있다.
4. 기능 요구 사항
다음 요구사항을 모두 만족해야 한다.

서비스 정체성과 기획
광고 대상은 통합 미션에서 만들 여행지 추천 웹 서비스로 하고, 그 서비스의 이름, 한 줄 소개, 톤앤매너를 정한다.
정한 내용을 스토리보드 문서 앞에 [서비스 정체성] 머리말을 붙인 블록으로 적는다. (지금 정한 이름과 톤은 다음 단계에서 다시 손볼 수 있다)
브랜드 아이덴티티에 대상 고객과 차별점(USP)을 함께 적는다.
캠페인 목표와 핵심 메시지를 한 문장으로 정의하고, 목표는 서비스를 알리는 인지, 한 번 써 보게 만드는 전환, 다시 오게 만드는 리텐션 가운데 하나로 정한다.
스토리보드 문서화
씬마다 씬 번호, 씬 길이, 목표 메시지, 화면 구성, 내레이션, 사용 도구, 사용 목적, 입력 프롬프트 원문, 출력 결과 요약, 생성 결과 파일명 또는 링크 10개 필드를 채우고 각 씬을 [씬 N] 머리말로 시작한다.
기승전결(문제 제시, 전개, 전환, 해결과 제안) 구조나 누구에게 어떤 가치를 주는지가 드러나는 가치 전달 구조 가운데 하나로 스토리라인을 구성하고 어느 쪽인지 적는다. 단순한 컷 나열은 충족하지 않는다. (10초에 넣지 않기로 한 장면과 그 기준을 적어 두면 동료 평가에서 근거로 쓸 수 있다)
멀티모달 생성 도구 사용
텍스트 생성, 이미지 생성, 영상 생성, 오디오 생성 도구를 각각 1종 이상 사용해 씬 소재를 만든다. (텍스트 생성 도구는 내레이션, 화면 구성, 목표 메시지, 마지막 장면 문구처럼 스토리보드에 적는 글에 쓴다. 영상 결과물을 만들어 내면 영상 생성 도구로 세며, 이미지를 받아 움직이게 하는 도구도 포함한다)
씬마다 어느 도구를 어떤 목적에 사용했는지 스토리보드 문서에 적는다. (무료 사용 구간과 대기열을 먼저 확인하고 씬 수와 생성 횟수를 정한다)
프롬프트 기록과 수정
씬마다 입력 프롬프트 원문과 출력 결과 요약을 기록하고, 의도한 결과가 나오지 않은 씬 하나 이상에 수정 전후 프롬프트와 수정 후 결과, 무엇을 왜 바꿨는지를 적는다. 이미 작성해 둔 프롬프트가 있으면 참고해도 되고 새로 작성해도 된다. (모든 씬이 한 번에 잘 나왔으면 의도에 가장 못 미친 씬을 대상으로 삼는다)
완성한 프롬프트 가운데 3건 이상에 카테고리를 함께 표시하고, 카테고리는 이미지 생성, 영상 생성, 오디오 생성 가운데 고른다.
영상 통합과 규격
생성한 소재의 해상도, 비율, 톤을 맞춰 5초 이상 10초 이내 영상 하나로 통합하고, 짧은 변이 720 픽셀 이상이 되게 한다. (통합하기 전에 씬 소재가 목표 메시지와 톤앤매너에 맞는지 한 번 보고, 맞지 않으면 다시 생성해 본다)
AI로 생성한 시각 요소와 청각 요소를 모두 넣고, 청각 요소는 음성, 효과음, 배경음악 가운데 하나 이상으로 한다.
영상 마지막 3~5초 구간에 로고, 브랜드명, 슬로건, 행동 유도 문구 가운데 하나 이상이 보이게 한다. 그 구간 전체를 전환 화면으로 채우지 않아도 되고 스토리라인의 마지막 장면에 겹쳐 보여도 충족한다.
완성한 영상의 파일명, 길이, 해상도를 스토리보드 문서에 적는다. (길이는 내보낸 파일의 재생 시간이며, 오디오가 영상보다 길면 파일이 그만큼 늘어난다)
도구 목록과 작업 기록
사용한 도구 목록과 생성 결과 파일명 또는 링크를 스토리보드 문서에 표기하고, 파일명을 붙인 규칙에 대한 설명을 함께 적는다.
미션을 수행하는 동안 무슨 작업을 했는지 기록한다. 건수와 서식은 정하지 않으며 한 항목이 무슨 작업이었는지 읽는 사람이 알 수 있게 적으면 충족한다.
작업 종류만 적지 않고 무엇을 어떻게 했는지가 드러나게 적는다.
여러 작업을 한 항목에 몰아 적지 않고 작업 하나를 한 항목으로 둔다. (시작할 때, 막혔을 때, 끝낼 때 한 줄씩만 적어도 충족한다)
5. 보너스 과제
인물이 말하는 장면을 하나 이상 더하고 입모양과 대사를 맞춘다.
요구사항 3에서 사용한 생성 도구와 씬 소재를 그대로 사용한다.
사용한 도구에 입모양을 맞추는 기능이 없으면 그 기능이 있는 도구를 하나 더해도 충족한다.
목소리와 화면이 조금만 어긋나도 보는 사람이 먼저 알아차린다는 것을 확인해 볼 수 있다.
이미지나 영상 생성 부분을 다른 도구로 바꿔 같은 씬 한둘을 다시 만든다.
요구사항 3에서 만든 씬과 그 씬에 넣은 입력 프롬프트를 그대로 사용한다.
프롬프트를 그대로 두고 도구만 바꿨을 때 결과가 어떻게 달라졌는지 기록한다.
도구를 선택한 근거를 한 번 더 확인해 볼 수 있다.
같은 스토리보드로 화면 비율 버전을 둘 이상 만든다.
요구사항 5에서 통합한 영상과 그때 사용한 소재를 그대로 사용한다.
비율이 달라질 때 어느 요소가 잘려 나가는지 기록한다.
같은 영상을 여러 매체에 올릴 때 겪는 일을 미리 경험해 볼 수 있다.
생성 도구 하나를 Google Apps Script 에서 API 로 연결해 요청을 보내고 받은 응답을 기록한다.
요구사항 3에서 사용한 생성 도구를 화면 대신 코드로 호출한다.
다른 도구로 수행해도 되며 도구를 바꾼 경우에는 무엇을 왜 골랐는지 한 줄 적는다.
고르려는 도구에 API 가 있는지 공식 문서에서 확인한 결과를 적는다. 없다는 확인도 충족한다.
결제 수단 등록이 필요해 키를 발급하지 못한 경우도 그 사실을 적으면 충족하며, 발급한 키는 제출물에 적지 않는다.
응답이 오류여도 충족한다. 생성 도구가 작업 큐를 두면 한 실행 안에서 결과가 오지 않으므로 요청을 보낸 기록과 받은 응답만 적어도 충족한다.
빈 스크립트에서 시작해도 되고 이미 만들어 둔 스크립트를 이어 써도 된다.
익히는 것은 언어 문법이 아니라 AI에게 작업을 지시해 코드를 받고 붙여 실행하는 절차이므로, 다음 단계에서 다른 언어를 다루더라도 같은 절차를 그대로 쓸 수 있다.
개발환경
6. 개발 환경
생성 도구: 텍스트 생성, 이미지 생성, 영상 생성, 오디오 생성 서비스 가운데 직접 고른 것
제품을 지정하지 않으므로 지금 접근할 수 있는 도구로 고른다. (무료 사용 구간, 크레딧, 대기열을 먼저 확인)
영상 편집 도구: 소재를 하나의 영상으로 통합할 때 쓸 도구를 직접 고른다.
가입 조건과 무료 출력의 제한(워터마크, 해상도)을 먼저 확인한다.
보너스 도구: Google Apps Script
보너스 과제 4에서만 사용한다. 브라우저에서 열리고 Google 계정 하나로 시작할 수 있다. (script.google.com 에서 새 프로젝트 만들기)
참고 사항: 필수 요구는 브라우저에서 열리는 도구만으로 수행할 수 있고 따로 설치하는 환경은 없다.
제약조건
7. 제약 사항
생성 소재의 출처와 사용 도구를 씬마다 표기한다.
출처와 사용 도구를 표기하지 않으면 어느 소재가 어느 도구에서 생성되었는지 확인할 수 없다.
실존 인물이나 상표를 생성 대상으로 사용하지 않는다.
실존 인물이나 상표를 생성 대상으로 사용하면 학습 산출물에서 초상권과 상표권 문제가 발생한다.
사용한 생성 도구의 이용 약관에서 결과물의 상업적 이용 가능 여부를 확인한다. (약관과 요금제 안내를 함께 본다. 광고를 올릴 매체가 정해져 있으면 그 매체의 AI 생성물 표시 조건도 확인한다)
광고는 공개를 전제로 만드는 결과물이고 생성 도구마다 결과물의 사용 조건이 다르다.
딥페이크, 혐오 표현, 선정성, 폭력 같은 유해 콘텐츠를 생성하지 않는다.
실존 인물을 사용하지 않더라도 생성한 인물로 동일한 소재를 제작할 수 있기 때문이다.
광고 대상은 통합 미션에서 만들 서비스로 고정한다.
임의의 브랜드를 사용하면 여기서 만든 결과물을 다음 단계에서 연계하여 사용할 수 없다.
직접 촬영한 소재와 유료 스톡은 사용하지 않는다. 소재는 생성 도구로 만든 결과를 주로 사용한다.
촬영 소재나 스톡이 섞이면 도구 비교와 프롬프트 기록을 증거로 사용할 수 없다.
생성 도구에 참고로 넣는 레퍼런스 이미지는 제한하지 않는다.
그 밖에 생성 결과가 아닌 이미지를 결과물 화면에 넣었다면 어느 씬인지 작업 기록에 밝힌다.
영상 편집 도구는 컷 편집(자르기와 이어 붙이기), 자막, 색보정, 오디오 레벨 조정, 크기와 비율 조정(비율을 맞추려고 여백을 덧대는 것 포함) 범위에서만 사용한다.
통합 편집 범위를 넘어 새로운 소재를 생성하는 데 사용하면 생성 도구 비교가 성립하지 않는다.
AI 활용 방향으로 소재 생성과 편집에 AI를 사용하는 것은 막지 않는다.
서비스 이름, 한 줄 소개, 톤앤매너는 직접 정한다.
씬마다 해당 도구를 선정한 이유도 사용 목적 칸에 직접 적는다.
