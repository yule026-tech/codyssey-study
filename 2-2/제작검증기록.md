**선택한 결과물과 근거:** 두 AI의 결과물을 비교했을 때 경험 추가·상세 보기·수정·삭제·저장 등 주요 기능에서 큰 차이는 없었다. 따라서 기능의 수보다 **디자인의 통일성, 첫 화면의 가독성, 사용 편의성**을 중심으로 선택하였다. ChatGPT 버전은 연보라·민트 그라데이션 헤더와 2열 카드가 조화롭게 구성되어 있고, 경험 목록과 필터·추가 버튼을 한눈에 파악하기 쉬웠다. 상세 화면도 필요한 내용을 섹션별로 확인할 수 있어 취업 준비용 개인 기록 페이지에 더 적합하다고 판단하여 **ChatGPT의 `커리어아카이브.html`을 최종 선택**하였다.

> 비교표는 **제출된 HTML 소스코드에서 확인한 구현과 디자인 구성**을 기준으로 작성했다. 브라우저에서의 두 결과물 비교 테스트는 별도로 확인해야 한다. 두 파일의 `localStorage` 키가 달라 저장된 경험 데이터가 서로 자동으로 공유되지 않는다.

## 수정 기록

### 수정 기록 1
- **발견한 문제:** 초기 기획·초기 버전의 예시 데이터보다, 실제 경험을 처음부터 직접 입력할 수 있는 빈 화면이 필요했다.
- **AI에게 전달한 요청:** 자동으로 들어가는 예시 경험을 제거하고, 저장된 기록이 없으면 빈 목록과 경험 추가 버튼을 표시하도록 요청했다.
- **수정 후 테스트 결과:** 최종 선택 파일의 초기 데이터 배열이 빈 배열이고, 저장 내용이 없을 때 빈 목록 안내를 표시하는 코드를 확인했다. **브라우저에서 직접 확인 후 최종 결과 기입 필요.**
- **수정 이유:** 실제 경력 기록과 가상의 예시 데이터가 섞이지 않도록 하기 위해서다.

### 수정 기록 2
- **발견한 문제:** 입력한 내용을 나중에 보완하거나 실수로 등록한 경험을 정리하기 어려웠다.
- **AI에게 전달한 요청:** 경험 상세 화면에 수정·삭제 버튼을 만들고, 삭제와 작성 취소 시 확인창을 표시하도록 요청했다.
- **수정 후 테스트 결과:** 최종 선택 파일에 수정·삭제 버튼과 확인창 처리 로직이 있는 것을 확인했다. **브라우저에서 직접 확인 후 최종 결과 기입 필요.**
- **수정 이유:** STAR·면접 답변을 나중에 보완할 수 있도록 하고 실수로 데이터를 잃는 상황을 줄이기 위해서다.

### 수정 기록 3
- **발견한 문제:** 경험을 등록해도 페이지를 다시 열 때 기록이 사라지면 개인 커리어 관리 도구로 사용하기 어렵다.
- **AI에게 전달한 요청:** 경험 추가·수정·삭제 결과를 브라우저 `localStorage`에 저장하고 재접속할 때 불러오며, 필수 항목은 별표로 구분하고 STAR·면접 항목은 선택 입력으로 처리하도록 요청했다.
- **수정 후 테스트 결과:** 최종 선택 파일에 `localStorage` 저장·불러오기, 필수 입력 검증, STAR·면접 항목 선택 입력 코드가 있는 것을 확인했다. **새로고침 후 데이터 유지 여부는 브라우저에서 직접 확인 필요.**
- **수정 이유:** 실제 활동 기록을 지속적으로 관리하고, 처음부터 모든 자기소개서·면접 내용을 완성하지 않아도 경험을 등록할 수 있도록 하기 위해서다.

> 이 수정 기록은 **최초 시안부터 최종 선택 파일까지의 개선 흐름**을 요약한 것이다. 이번 ChatGPT·Claude 재비교 이후에 새로 수정한 사항을 의미하지는 않는다.

## 사용자 테스트

- **테스트 참여자와 요청한 작업:** 제작자 본인. 경험을 추가하고, 유형 필터를 적용하고, 상세 내용을 확인하며, 수정·삭제와 새로고침 후 저장 유지 여부를 점검하는 시나리오를 준비함.
- **사용자의 행동과 질문:** 직접 활동을 입력하는 과정에서 초기 예시 데이터가 필요하지 않고, 작성한 내용을 수정·삭제하며 저장할 수 있어야 한다는 요구사항을 제시함. 두 결과물 비교 시 기능보다 목록의 배치, 화면의 인상과 가독성을 주요 선택 기준으로 고려함.
- **받은 피드백:** 제작자 본인 의견으로, 두 AI가 만든 결과물의 기능 차이는 크지 않으며 ChatGPT 버전의 디자인과 화면 구성이 더 마음에 든다고 판단함. **제3자의 별도 사용자 테스트는 아직 확인되지 않음.**
- **반영 내용과 결과:** 예시 데이터 제거, 수정·삭제·저장 기능 추가, 필수·선택 항목 구분을 최종 기획에 반영했고, 두 결과물 중 ChatGPT의 디자인을 선택함. 외부 사용자 피드백 및 브라우저 조작 결과는 확인 후 추가 예정.
