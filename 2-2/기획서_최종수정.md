# My Career Archive - 취업 준비용 커리어 아카이브

## 대상 사용자

- 취업을 준비하면서 프로젝트, 대외활동, 교육 이력을 개인적으로 정리하고 자기소개서 및 면접 준비에 활용하려는 본인.
- 노트북이나 휴대폰의 웹 브라우저에서 경험을 기록하고 확인한다.

## 사용 목적

- 여러 곳에 흩어진 활동 경험을 유형별로 정리하고 활동 기간, 담당 역할, 주요 업무와 성과를 빠르게 확인한다.
- 경험별 STAR(상황·과제·행동·결과)와 면접 예상 질문 및 답변을 기록하고, 추후 수정하면서 취업 준비 자료로 활용한다.
- 경험을 직접 추가·수정·삭제하고 새로고침 후에도 기록을 유지한다.

## 화면 구성과 동작

- 맨 위에 `My Career Archive` 제목과 `나의 경험을 기록하는 공간 ✨` 문구를 표시한다. 밝은 배경에 연보라·민트 계열 포인트 색상을 사용하고, 넓은 화면에서는 경험 카드를 2열로 배치한다.
- 처음 실행했을 때 예시·더미 경험을 자동으로 표시하지 않는다. 저장된 기록이 없다면 `등록된 경험이 없습니다` 안내와 `+ 경험 추가` 버튼을 보여준다. 저장된 기록이 있으면 자동으로 불러온다.
- 경험 목록 상단에 `전체`, `프로젝트`, `대외활동`, `교육` 필터 버튼과 총 경험 수 및 현재 표시 수를 보여준다. 필터를 누르면 해당 유형의 경험만 표시된다. 경험 카드는 활동 종료일 기준 최신순으로 정렬한다.
- 카드에는 활동 유형, 활동명, 시작일·종료일, 담당 역할을 표시한다. 카드를 누르면 별도의 상세 화면으로 이동하며, `기본 정보 → 주요 활동 및 수행 업무 → 성과 및 배운 점 → 자소서용 STAR 정리 → 면접 예상 질문과 답변 핵심 내용` 순서로 내용을 보여준다. `← 목록으로`로 돌아간다.
- `+ 경험 추가`를 누르면 입력 화면이 열린다. `활동명`, `유형`, `담당 역할`, `시작일`, `종료일`, `주요 활동 및 수행 업무`, `성과 및 배운 점`은 빨간 별표(`*`)로 필수임을 표시한다. STAR의 상황·과제·행동·결과와 면접 질문·답변은 선택 입력이며, 비워 두면 상세 화면에 `아직 작성하지 않았습니다`라고 표시한다.
- 필수 항목을 누락하거나 종료일을 시작일보다 빠르게 지정한 상태에서 저장하면 안내 문구를 띄우고 해당 경험을 추가·수정하지 않는다. 정상 입력 후 `추가하기`를 누르면 카드가 목록에 반영된다.
- 상세 화면에서 `수정` 버튼을 누르면 기존 내용이 채워진 입력 화면을 열어 변경할 수 있다. `수정 완료`를 누르면 내용이 갱신된다. `삭제` 버튼을 누르면 삭제 확인창이 나타나고, 확인해야만 경험이 삭제된다.
- 입력 화면의 `취소` 또는 `← 목록으로`를 누르면 목록으로 돌아간다. 작성 중 변경한 내용이 있으면 취소 여부를 한 번 더 확인한다.
- 추가·수정·삭제한 경험은 브라우저의 `localStorage`에 저장하고 다시 열 때 불러온다. 저장 실패 시 안내한다.
- 좁은 화면에서는 카드와 입력 항목이 1열로 바뀌며, 가로 스크롤 없이 내용을 읽고 버튼을 누를 수 있도록 한다.

## 필요한 자료

- 본인의 프로젝트·대외활동·교육 경험에 관한 활동명, 유형, 실제 시작일·종료일, 담당 역할, 주요 활동, 성과 및 배운 점.
- 경험별 STAR 내용과 면접 대비 질문·답변(선택적으로 입력하며 추후 보완 가능).
- 작성할 수 있는 실제 경험 예: Moodly 앱 개발, BlueRoom 졸업 프로젝트, 쉬운 고지서 AI 웹앱, 코더스 SW 교육 봉사, 코디세이 AI 활용 교육. 해당 이름들은 *기획·입력 대상의 예시*이며 최초 화면에 자동으로 삽입하지 않는다.
- **자료 출처 및 권한:** 본인의 활동 기록, 수업·프로젝트 결과물 등 직접 확인한 자료와 본인이 작성한 문구를 사용한다. 실제 확인하지 않은 성과나 날짜는 만들어 넣지 않는다. 초기 구현에는 외부 사진·글꼴·라이브러리를 사용하지 않는다.

## 완료 기준

1. 처음 실행하고 저장된 경험이 없을 때 카드 수는 `0개`이고 예시 데이터 없이 빈 목록 안내와 `+ 경험 추가` 버튼이 표시된다.
2. 필수 항목을 올바르게 작성해 경험 1개를 추가하면 카드 수가 `0개 → 1개`로 바뀌며 해당 카드에 활동명·유형·기간·역할이 표시된다.
3. `프로젝트` 유형으로 경험을 추가한 뒤 `프로젝트` 필터를 누르면 해당 카드만 보인다. `전체`를 누르면 모든 등록 카드가 보인다.
4. 경험 카드를 누르면 기본 정보, 주요 활동, 성과, STAR 4항목, 면접 질문과 답변을 순서대로 확인할 수 있다. 선택 입력을 비웠다면 `아직 작성하지 않았습니다`라고 표시된다.
5. 경험 상세 화면에서 `수정`을 누르고 활동명을 바꿔 저장하면 목록 및 상세 화면에 변경된 활동명이 표시된다.
6. 경험 상세 화면에서 `삭제`를 누르고 확인창에서 취소하면 카드가 남으며, 확인하면 카드가 제거되고 전체 개수가 1개 감소한다.
7. 필수 입력값을 비우거나 종료일을 시작일보다 빠르게 입력하면 오류 안내가 표시되고 경험이 등록·변경되지 않는다. 입력한 내용을 변경한 뒤 `취소`를 누르면 확인 메시지가 나타난다.
8. 경험을 추가 또는 수정하고 브라우저에서 새로고침하면 같은 브라우저의 동일 페이지 주소에서 저장된 카드와 변경 내용이 유지된다.
9. 휴대폰 너비의 좁은 화면에서는 카드와 입력 항목이 1열로 표시되고 가로 스크롤 없이 사용할 수 있다.
10. CSS와 JavaScript를 포함한 **HTML 파일 1개**를 로그인·서버·API 키·외부 라이브러리·인터넷 연결 없이 브라우저에서 직접 열 수 있다.

## 필수 기능

- 예시 데이터 없는 초기 화면과 사용자 경험 추가
- 활동 종료일 기준 최신순 카드 목록 및 유형별 필터
- 경험 상세 보기(STAR·면접 대비 포함)
- 경험 수정·삭제 및 삭제/취소 확인
- 필수 입력 표시, 빈칸·날짜 유효성 검사, STAR·면접 내용 선택 입력
- 브라우저 `localStorage` 저장·불러오기
- 모바일 반응형 화면 및 단일 HTML 파일 실행

## 추가 기능

- 경험 기록을 JSON 파일로 내보내고 다른 기기에서 가져오는 백업·복원 기능
- 활동명 또는 키워드 검색, 경험 타임라인 표시
- 로그인 및 계정 간 동기화(향후 서버를 도입할 경우 검토)

## 한계 및 비목표

1. 경험 데이터는 현재 브라우저의 `localStorage`에만 저장된다. 다른 브라우저·기기와 자동으로 공유되지 않으며, 브라우저 데이터 삭제나 저장소 제한으로 기록이 사라질 수 있다.
2. 이번 버전에는 클라우드 백업, 로그인·회원 관리, 서버·DB 동기화 기능을 구현하지 않는다.
3. AI가 자기소개서나 면접 답변을 자동 생성하거나 입력 내용의 사실 여부를 검증하는 기능은 구현하지 않는다. 활동 정보의 정확성은 사용자가 직접 확인한다.

## 검증 방법

- 실제 경험 하나에 대해 원본 활동 기록(예: 프로젝트 보고서·교육 자료)에서 **활동명, 기간, 담당 역할, 주요 업무, 성과**를 확인한다. 해당 정보를 페이지에 입력한 뒤 상세 화면 내용과 항목별로 대조한다. 이어서 한 항목을 수정하고 새로고침한 뒤 저장된 값이 그대로 표시되는지 확인한다. 누락 또는 불일치한 항목이 있으면 기록해 수정한다.

## 사용한 AI 서비스와 모델

- **기획서 작성 AI:** OpenAI ChatGPT / GPT-6
- **활용 과정:** AI의 질문에 답하며 페이지의 사용자·목적·기능·완료 기준을 정했고, 구현 결과와 사용 중 발견한 개선 필요 사항을 바탕으로 초기 예시 데이터 제거, 경험 수정·삭제 및 브라우저 저장 기능을 추가하는 방향으로 기획서를 보완했다.
- **HTML 비교 제작 AI:** 두 서비스·모델 이름은 실제 생성 시 확인해 `제작검증기록.md`에 각각 기록한다.
