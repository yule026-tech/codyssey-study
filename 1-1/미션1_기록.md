## AI가 물어서 내가 정한 것

- **사용자와 목적:** 나 혼자 사용하면서 지금까지 본 영화를 취향대로 분류하고, 정리한 결과를 다른 사람에게 보여 주거나 영화를 추천할 때 활용하고 싶었다. 온라인 계정이나 공유 기능은 이번 버전에 넣지 않고, 먼저 개인용 웹페이지로 만들기로 했다.
- **등급과 배치:** S·A·B·C의 네 등급을 사용하고, 화면 위쪽에 등급별 칸을, 아래쪽에 미분류 영화를 배치하기로 했다.
- **영화 이동:** 카드를 끌어서 이동하는 방법과 카드를 눌러 등급을 선택하는 방법을 모두 제공하기로 했다.
- **초기 영화:** 제공된 예시 목록 대신 내가 감상한 영화 8편(인사이드 아웃, 나우 유 씨 미, 뷰티 인사이드, 기생충, 라라랜드, 해리포터, 왕과 사는 남자, 나의 소녀시대)으로 시작하기로 했다.
- **영화 추가:** 제목을 입력해 영화를 추가할 수 있게 하고, 같은 제목을 중복 입력하면 안내하도록 했다.
- **개인 평가:** 별점은 1~5점의 정수 단위로 선택하게 하고, 감상평·추천 이유는 짧은 메모에 쓰도록 했다. 별점과 메모 모두 필수가 아니라 선택적으로 입력하도록 결정했다.
- **저장과 초기화:** 같은 브라우저에서 다시 열어도 등급·별점·메모·추가 영화가 유지되게 하고, 전체 초기화는 확인창을 거쳐 처음 8편이 모두 미분류인 상태로 돌아가게 했다.
- **디자인:** 어두운 영화관 느낌을 기본으로 하고, 디자인 수정 과정에서는 영화관의 붉은 좌석이 연상되는 검정·버건디 계열의 색감을 강조하기로 했다.

## 같은 행동으로 비교한 결과

같은 기획서로 ChatGPT(A)와 Claude(B)에 HTML 생성을 요청했다. 두 파일을 직접 열어 주요 기능을 비교했고, **두 결과물 모두 기능이 잘 작동하여 뚜렷한 성능 차이를 느끼지 못했다.** 아래 표는 비교를 기록하기 위한 구체적 예시이며, 제출 전에 실제 수행한 동작과 일치하는지 한 번 더 확인한다.

| 해본 행동 | 기대 결과 | A의 결과 | B의 결과 |
|---|---|---|---|
| 영화 카드를 S/A/B/C 등급으로 이동하기 | 선택한 등급 칸으로 이동하고 원래 칸에서 사라짐 | 정상 작동 | 정상 작동 |
| 영화 카드를 클릭해 등급 변경하기 | 선택한 등급으로 변경됨 | 정상 작동 | 정상 작동 |
| 새로운 영화 제목 추가하기 | 미분류에 새 영화 카드가 생김 | 정상 작동 | 정상 작동 |
| 이미 있는 제목 다시 추가하기 | 중복 안내가 표시되고 새 카드가 생기지 않음 | 정상 작동 | 정상 작동 |
| 선택적으로 별점과 감상평 작성하기 | 입력한 평가를 저장하고 다시 확인할 수 있음 | 정상 작동 | 정상 작동 |
| 같은 브라우저에서 파일 다시 열기 | 저장한 영화 분류와 입력 내용이 유지됨 | 정상 작동 | 정상 작동 |
| 전체 초기화하기 | 확인 후 처음 영화 8편이 미분류로 돌아감 | 정상 작동 | 정상 작동 |

**기능 외 비교:** 두 AI가 만든 웹페이지 모두 필요한 기능을 구현했지만, A안의 화면이 좀 더 깔끔하고 정돈되어 있어 내 취향에 잘 맞았다. 따라서 기능 성능의 차이를 억지로 구분하기보다 디자인과 화면 가독성을 기준으로 선택했다.

## 선택한 파일명과 고른 이유

- **선택한 초안:** `영화_A_초안.html` (ChatGPT)
- **고른 이유:** A와 B의 기능이 모두 잘 작동해 기능만으로는 우열을 가리기 어려웠다. 하지만 A안이 전체적으로 더 깔끔하고 정돈된 디자인이어서 더 마음에 들었다. A안을 바탕으로 색상과 카드 구성을 내 취향에 맞게 다듬으면 원하는 영화관 분위기를 더 살릴 수 있다고 판단했다.
- **수정 후 최종 선택 파일:** `영화_A안_수정본.html`
