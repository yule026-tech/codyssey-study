# 나만의 영화 티어리스트 기획서

## 1. 누가 쓰나

- 내가 지금까지 감상한 영화를 개인 취향에 따라 정리하기 위해 혼자 사용하는 웹페이지다.
- 등급을 정하는 사람은 나 한 명이지만, 정리한 화면을 친구나 지인에게 보여 주거나 화면 캡처로 공유해 영화를 추천하는 데에도 활용한다.
- 다른 사람이 직접 등급을 수정하는 기능이나 회원가입·온라인 공유 기능은 이번 버전에서 만들지 않는다.

## 2. 무엇을 하려고

- 지금까지 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 한눈에 정리한다.
- 영화별로 원한다면 1~5점의 별점과 짧은 감상평 또는 추천 이유를 남겨 기억을 기록한다. 별점과 메모는 **선택 사항**이며, 입력하지 않아도 영화를 분류하거나 저장할 수 있어야 한다.
- 정리된 결과를 보여 주면서 다른 사람에게 내가 좋아하는 영화를 추천할 수 있도록 한다.

## 3. 화면과 동작

### 화면 구성과 디자인

- 웹페이지는 **어두운 영화관 분위기**로 디자인한다. 검정·짙은 남색을 중심 색으로 사용하고, 영화관의 스크린이나 조명에서 연상되는 은은한 강조색을 적용한다.
- 페이지 상단에 제목과 S·A·B·C 등급별 칸을 배치하고, 그 아래에 아직 등급을 정하지 않은 영화 목록(미분류)을 둔다.
- 각 영화는 제목이 보이는 카드로 표시한다. 등급별 칸은 구별하기 쉽고, 좁은 화면에서도 내용이 잘리지 않도록 구성한다.
- 별도 이미지 파일, 서버, 로그인 없이 HTML 파일 한 개로 실행할 수 있도록 한다.

### 영화 분류 및 상세 정보

- 처음 실행하면 내가 직접 선정한 영화 8개를 모두 **미분류**에 표시한다.
- 영화 카드를 원하는 등급 칸으로 드래그하여 옮길 수 있다.
- 영화 카드를 클릭하면 상세 영역이 열리며, 여기서 **등급 변경 메뉴**로 S·A·B·C 또는 미분류 중 원하는 위치를 선택할 수 있다.
- 상세 영역에는 **1~5점 정수 단위 별점**과 **짧은 메모 입력란**이 있다. 메모에는 감상평이나 추천 이유를 자유롭게 적는다.
- 별점과 메모를 비워 두는 것도 허용하며, 빈 값 때문에 경고가 뜨거나 저장이 막히지 않는다.

### 영화 추가, 저장, 초기화

- 영화 제목을 입력하고 추가 버튼을 누르면 새 영화 카드가 미분류 목록에 생긴다.
- 공백만 입력하거나 이미 있는 영화 제목을 다시 입력하면 카드를 만들지 않고 안내 문구를 표시한다.
- 영화 목록, 등급 배치, 별점, 메모는 브라우저의 로컬 저장소에 자동 저장한다. 같은 브라우저에서 파일을 다시 열어도 마지막 상태가 유지된다.
- **전체 초기화** 버튼을 누르면 확인창이 나타난다. 취소하면 현재 상태가 그대로 유지된다.
- 초기화를 확인하면 추가했던 영화와 기록한 별점·메모가 삭제되고, 처음 선정한 영화 8개가 모두 미분류 상태로 돌아간다.

## 4. 필요한 자료

- 초기 영화 제목 8개 (사용자가 실제로 감상한 작품으로 직접 선정)
  1. 인사이드 아웃
  2. 나우 유 씨 미
  3. 뷰티 인사이드
  4. 기생충
  5. 라라랜드
  6. 해리포터
  7. 왕과 사는 남자
  8. 나의 소녀시대
- 등급: S, A, B, C, 미분류
- 사용자가 추가하는 영화 제목과 선택적으로 입력하는 별점(1~5점), 짧은 메모
- 영화 포스터, 외부 영화 데이터, 계정 정보는 필요하지 않다.

## 5. 완성 기준

아래 항목은 완성된 HTML 파일을 브라우저에서 직접 열어 확인한다.

1. 처음 열었을 때 영화 8개가 미분류에 나타나고, 위에는 S·A·B·C 등급 칸이 보인다.
2. `기생충` 카드를 S칸으로 드래그하면 S칸에만 나타나고 미분류에서는 사라진다.
3. `라라랜드` 카드를 클릭해 상세 영역에서 A등급을 선택하면 A칸으로 이동한다.
4. 새 제목을 입력하고 추가하면 해당 영화 카드가 미분류에 생긴다.
5. 이미 있는 영화 제목을 다시 추가하거나 공백만 입력하면 새 카드가 생기지 않고 안내가 표시된다.
6. 영화 카드의 상세 영역에서 별점을 4점으로 정하고 메모를 입력하면 해당 값이 표시된다.
7. **별점과 메모를 작성하지 않은 영화도** 정상적으로 등급을 이동하고 저장할 수 있다.
8. 영화의 등급·추가한 제목·별점·메모를 변경한 뒤 같은 브라우저에서 HTML 파일을 다시 열면 변경 사항이 남아 있다.
9. 전체 초기화 버튼을 누르고 취소하면 영화 배치와 기록이 변하지 않는다.
10. 전체 초기화를 확인하면 새로 추가한 영화와 별점·메모가 없어지고, 내가 선정한 영화 8개가 모두 미분류로 돌아간다.
11. 화면 너비를 좁혀도 영화 제목과 주요 조작 기능이 잘리지 않고 사용할 수 있다.
12. 인터넷 연결이나 별도 서버 실행 없이 HTML 파일 하나를 브라우저에서 열어 주요 기능을 사용할 수 있다.

> **공유 범위:** 이번 버전에서 '공유'는 완성된 티어리스트 화면을 직접 보여 주거나 캡처하여 전달하는 것을 뜻한다. 여러 사용자가 웹에서 동시에 접속하거나 데이터를 공유하는 기능은 포함하지 않는다.
