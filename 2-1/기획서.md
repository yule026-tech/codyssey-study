# My Career Archive - 취업 준비용 커리어 아카이브

## 대상 사용자

- 취업을 준비하는 나. 프로젝트·대외활동·교육 경험을 모아 두고 자기소개서 작성이나 면접 준비를 할 때 노트북과 휴대폰으로 확인합니다.

## 사용 목적

- 여러 곳에 흩어진 활동 경험을 한 페이지에서 찾아보고, 내가 맡은 역할과 성과를 정리합니다.
- 경험별 STAR(상황·과제·행동·결과)와 면접 예상 질문을 확인해 자기소개서 및 면접 답변의 소재로 활용합니다.
- 새로운 경험이 생기면 현재 열린 페이지의 목록에 추가합니다.

## 화면 구성과 동작

- 맨 위에 'My Career Archive'와 '나의 경험을 기록하는 공간 ✨'이라는 안내 문구가 나옵니다.
- 그 아래 '나의 경험 목록'에 처음 준비한 실제 활동 5개가 카드로 표시됩니다. 카드는 활동 종료일이 최근인 순서로 정렬하고, 각 카드에는 활동명·유형·기간·담당 역할을 적습니다.
- 목록 위에는 '전체', '프로젝트', '대외활동', '교육' 필터 버튼이 있습니다. 처음에는 '전체'가 선택됩니다. '프로젝트'를 누르면 프로젝트 카드만, '전체'를 누르면 모든 카드가 나옵니다.
- 경험 카드를 누르면 같은 페이지에서 상세 정보가 열립니다. '기본 정보 → 주요 활동 및 수행 업무 → 성과 및 배운 점 → 자소서용 STAR 정리 → 면접 예상 질문과 답변 핵심 내용' 순서로 표시합니다.
- '+ 경험 추가'를 누르면 활동명, 유형, 시작일·종료일, 역할, 주요 활동, 성과·배운 점, STAR 4개 항목, 면접 질문과 답변 핵심 내용을 입력하는 양식이 열립니다.
- 필수 항목을 모두 입력하고 '추가하기'를 누르면 새 카드가 목록에 나타나고 필터 및 상세 보기에도 반영됩니다. 빈 항목이 있거나 종료일이 시작일보다 빠르면 안내 메시지를 띄우고 추가하지 않습니다.
- 컴퓨터에서는 경험 카드를 목록으로 읽고, 휴대폰에서는 가로로 밀지 않고 카드와 상세 내용을 세로로 확인할 수 있도록 구성합니다.

## 필요한 자료

- 실제 프로젝트·대외활동·교육 경험 5개의 활동명, 유형, 시작일·종료일, 담당 역할, 주요 활동, 성과 및 배운 점
- 경험별 자소서용 STAR 4개 항목(상황·과제·행동·결과), 면접 예상 질문과 답변 핵심 내용
- **출처:** 본인이 작성한 활동 기록, 프로젝트 결과물, 교육 관련 기록 등을 확인해 직접 입력합니다. 실제 경험 5개의 상세 내용은 HTML 제작 전에 준비합니다.
- **사용 권한:** 본인의 기록과 직접 작성한 글을 사용합니다. 초기 버전에는 외부 사진·글꼴·라이브러리를 사용하지 않습니다.

## 완료 기준

- HTML 파일을 열면 미리 준비한 실제 경험 카드 5개가 최근 활동순으로 표시됩니다.
- '프로젝트'를 누르면 프로젝트 유형의 카드만 나오고, '전체'를 누르면 5개가 다시 모두 나옵니다.
- 경험 카드를 누르면 활동 기간·담당 역할·주요 활동·성과가 나오고, STAR의 상황·과제·행동·결과 4개 항목과 면접 예상 질문·답변 핵심 내용을 확인할 수 있습니다.
- '+ 경험 추가'를 누르면 입력 양식이 열립니다. 올바른 새 경험 1개를 입력하고 '추가하기'를 누르면 전체 카드 수가 5개에서 6개로 늘어납니다.
- 새 경험에 '교육' 유형을 선택해 추가한 뒤 '교육' 필터를 누르면 새 카드가 표시됩니다.
- 필수 입력 항목을 비우거나 종료일을 시작일보다 빠르게 입력하면 카드가 추가되지 않고 안내 문구가 나옵니다.
- 휴대폰 너비의 화면에서도 가로 스크롤 없이 경험 카드와 상세 내용을 읽을 수 있습니다.
- 다른 파일이나 로그인·서버·인터넷 연결 없이 HTML 파일 하나를 브라우저에서 직접 열어 사용할 수 있습니다.

## 필수 기능

- 실제 경험 5개의 카드 목록 및 최신 활동순 표시
- 유형별 필터(전체·프로젝트·대외활동·교육)
- 경험 상세 보기(STAR 정리와 면접 대비 내용 포함)
- 경험 추가와 필수 항목·활동 기간 입력 검증
- 단일 HTML 파일 실행 및 좁은 화면 대응

## 추가 기능

- 기존 경험 수정 및 삭제
- 새로 추가한 경험의 영구 저장 및 다시 불러오기
- 활동명·키워드 검색과 경험 타임라인 표시

## 한계 및 비목표

1. 처음 제공하는 실제 경험은 5개이며, 이후 추가한 경험은 현재 열린 페이지에서만 확인할 수 있습니다.
2. 기존 경험의 수정·삭제와 입력 내용의 영구 저장은 구현하지 않습니다. 새로고침하거나 창을 닫으면 추가한 경험이 사라집니다.
3. 로그인·회원 관리·서버 연동 및 AI를 통한 자기소개서 자동 생성은 구현하지 않습니다.

## 검증 방법

- 본인의 원본 활동 기록 5개를 준비합니다. HTML 파일을 열어 '전체' 목록의 카드 5개를 각각 선택한 뒤, 화면에 적힌 **활동명·활동 기간·담당 역할·성과 및 배운 점**을 원본 기록과 항목별로 대조합니다. 누락되거나 다른 내용은 입력 자료를 수정하고 다시 비교합니다.

## 사용한 AI 서비스와 모델

- **AI 서비스:** OpenAI ChatGPT
- **모델:** GPT-6
- **활용 과정:** AI가 질문한 대상 사용자·사용 목적·화면 구성·필요한 자료·완료 기준 등에 답하면서 기획을 구체화하고, 작성 예시와 양식에 맞춰 기획서 문장을 검토했습니다.
