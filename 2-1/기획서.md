# 취업 준비용 커리어 아카이브 HTML 페이지 기획서

## 1. 프로젝트 개요
- **페이지 이름:** My Career Archive (취업 준비용 커리어 아카이브)
- **제작 형태:** 별도 로그인이나 서버 없이 웹 브라우저에서 직접 열 수 있는 단일 HTML 페이지 (`index.html`)
- **기획 목적:** 개인 활동 경험을 한곳에 모아 자기소개서 작성과 면접 준비에 활용한다.

## 2. 대상 사용자
- 취업을 준비하는 본인 1명
- 개인 프로젝트, 대외활동, 교육 경험을 정리하고 필요할 때 찾아보려는 사용자

## 3. 사용 목적
1. 프로젝트·대외활동·교육 경험 5개를 한 페이지에서 살펴본다.
2. 각 경험의 담당 역할, 주요 활동, 성과와 배운 점을 확인하여 자기소개서 소재를 찾는다.
3. 경험별 STAR 정리와 면접 예상 질문 및 답변 핵심 내용을 확인하여 면접을 준비한다.
4. 새로운 활동 경험을 입력하여 현재 열려 있는 페이지의 경험 목록에 추가한다.

## 4. 화면 구성과 동작
### 4-1. 메인 화면(경험 목록)
- 상단에 `My Career Archive`와 안내 문구 `나의 경험을 기록하는 공간 ✨`을 표시한다.
- 메인 화면에 `나의 경험 목록`을 바로 보여준다. 별도의 `전체 경험` 메뉴나 `나의 역량`, `자소서 소재` 메뉴는 만들지 않아 중복을 피한다.
- 경험 목록 위에 `전체`, `프로젝트`, `대외활동`, `교육` 필터 버튼과 `+ 경험 추가` 버튼을 둔다.
- 초기에는 실제 활동 경험 5개를 **최근 활동부터** 카드 형태로 표시한다(활동 종료일 기준 내림차순; 종료일이 같으면 입력 순서 유지).
- 카드에는 **활동명, 활동 유형, 활동 기간, 담당 역할**을 간략하게 표시한다.

### 4-2. 필터와 경험 상세 보기
- 처음 열면 `전체` 필터가 선택되어 초기 경험 5개가 표시된다.
- 카테고리 버튼을 누르면 그 유형의 카드만 표시되고 `전체`를 누르면 추가된 경험을 포함한 모든 카드를 표시한다.
- 경험 카드를 선택하면 동일한 페이지 안의 상세 영역에서 다음 순서로 표시한다.
  1. 기본 정보(활동명, 유형, 기간, 역할)
  2. 주요 활동 및 수행 업무
  3. 성과 및 배운 점
  4. 자기소개서 소재: 상황(Situation), 과제(Task), 행동(Action), 결과(Result)
  5. 면접 예상 질문과 답변 핵심 내용
- STAR와 면접 대비는 별도 메인 메뉴가 아니라 **각 경험의 상세 정보 안**에 포함한다.

### 4-3. 경험 추가 기능
- `+ 경험 추가` 버튼을 누르면 입력 양식이 나타난다.
- 입력 항목은 활동명, 유형(프로젝트/대외활동/교육), 시작일·종료일, 담당 역할, 주요 활동, 성과 및 배운 점, STAR 4개 항목, 면접 예상 질문과 답변 핵심 내용이다.
- 모든 항목을 입력하고 `추가하기` 버튼을 누르면 새 경험 카드가 목록에 나타나며 유형별 필터와 상세 보기에도 반영된다.
- 필수 항목이 비어 있거나 종료일이 시작일보다 빠르면 카드가 추가되지 않고 안내 메시지를 표시한다.
- **이번 버전은 추가만 가능**하며 기존 경험의 수정·삭제는 지원하지 않는다. 추가한 내용은 브라우저 새로고침이나 종료 후에는 유지되지 않는다(영구 저장 기능 제외).
- CSS와 JavaScript를 HTML에 포함하여 외부 파일·로그인·서버 없이 실행한다.

## 5. 필요한 자료
- 본인의 **실제 활동 경험 5개**: 프로젝트, 대외활동, 교육 활동 중 해당하는 경험
- 경험별 필수 데이터:
  - 활동명과 활동 유형(프로젝트/대외활동/교육 중 하나)
  - 활동 기간
  - 담당 역할
  - 주요 활동 및 수행 업무
  - 성과 및 배운 점
  - 자기소개서용 STAR 4개 항목(상황·과제·행동·결과)
  - 면접 예상 질문과 답변 핵심 내용
- **자료 출처:** 본인이 작성한 활동 기록, 프로젝트 산출물, 교육 수료 관련 기록 등 본인이 보유한 원본 자료. 실제 정보와 대조해 내용을 입력한다.
- **사용 권한:** 본인의 기록과 직접 작성한 문장만 사용한다. 제3자의 사진, 글, 글꼴, 라이브러리 등 외부 저작물은 초기 버전에서 사용하지 않는다.
- **자료 준비 상태:** 활동 5개의 구체적인 내용은 아직 제공되지 않았으므로, 실제 HTML 구현 전에 원본 자료를 정리해 입력한다. 이 기획서에서 개별 활동명이나 성과를 임의로 생성하지 않는다.

## 6. 필수 기능
1. **경험 카드 목록:** 초기 실제 활동 5개를 최근 활동순으로 표시한다.
2. **카테고리 필터:** `전체`, `프로젝트`, `대외활동`, `교육`을 선택하여 카드를 분류한다.
3. **경험 상세 보기:** 경험 카드를 선택하면 기본 정보 → 주요 활동 → 성과 및 배운 점 → STAR → 면접 대비 순서로 표시한다.
4. **경험 추가:** `+ 경험 추가` 버튼으로 새 경험을 입력하면 현재 페이지의 목록에 추가된다.
5. **입력 검증:** 필수 항목 누락이나 잘못된 기간을 검사하여 잘못된 데이터 추가를 막는다.
6. **독립 실행:** 단일 HTML 파일을 브라우저에서 직접 열어 위 기능을 사용할 수 있다.

## 7. 추가 기능(이번 구현 범위에서 제외)
- 기존 경험 수정 및 삭제
- 경험 데이터의 영구 저장(브라우저 재방문 시 유지 또는 파일로 내보내기)
- 키워드 검색 및 타임라인 시각화
- 로그인, 서버 연동, AI 자기소개서 자동 생성

## 9. 한계 및 비목표(3가지)
1. **초기 자료 범위:** 처음 제공하는 실제 경험은 5개이며, 사용자가 더 입력해 현재 화면에서 추가할 수 있다.
2. **수정·삭제·영구 저장 제외:** 추가는 가능하지만 기존 경험 수정·삭제 및 새로고침 후 입력 내용 유지 기능은 구현하지 않는다.
3. **계정·서버 제외:** 로그인, 회원 관리, 서버 연동 및 AI 자기소개서 자동 생성 기능은 구현하지 않는다.

## 10. 검증 방법(1가지)
**원본 활동 기록과 웹페이지 표시 내용의 대조 검사**
1. 본인이 보유한 원본 활동 기록 5개(활동 보고서, 프로젝트 기록, 교육 기록 등)를 준비한다.
2. 웹페이지를 처음 열어 `전체` 필터를 선택하고 초기 카드 5개를 순서대로 연다.
3. 각 카드의 **활동명, 활동 기간, 담당 역할, 성과 및 배운 점**을 해당 원본 기록과 항목별로 비교한다.
4. 내용이 일치하면 통과로 기록하고, 누락되거나 다른 항목이 있으면 HTML의 입력 데이터를 수정한 뒤 재확인한다.

## 11. 사용한 AI 서비스 및 모델
- **AI 서비스:** OpenAI ChatGPT
- **AI 모델:** GPT-6
- **활용 내용:** AI의 단계별 질문에 답하며 주제, 대상 사용자, 사용 목적, 화면 구성, 필수·추가 기능, 필요한 자료, 완료 기준, 한계 및 비목표, 검증 방법을 구체화하고 기획서 초안을 작성함.
- **사용자 검토:** 본인이 선택한 사항을 기준으로 기획서를 검토했으며, 실제 경험 5개의 구체적인 사실은 후속 구현 전에 원본 자료로 확인할 예정임.

## 12. 모호한 표현 검토 및 구체화
- `경험을 정리한다` → `초기 실제 활동 5개를 최근 활동순 카드로 보여주고 유형별 필터로 찾으며 새 경험을 추가한다`로 명확히 했다.
- `상세 정보를 보여준다` → `기본 정보, 주요 활동, 성과 및 배운 점, STAR, 면접 대비` 순서로 항목을 지정했다.
- `자소서 소재` → STAR의 4개 항목을 경험별로 보여주는 것으로 정의했다. 자동으로 자기소개서를 생성하는 기능을 의미하지 않는다.
- `면접 대비` → 예상 질문과 답변 핵심 내용을 표시하는 기능으로 정의했다. AI 모의 면접을 뜻하지 않는다.
- `경험 추가` → 필수 입력 항목을 검사하고 정상 입력 시 현재 목록에 카드를 한 개 추가하는 동작으로 정의했다. 추가 데이터는 새로고침 시 사라진다는 한계도 명시했다.
- `다른 파일 없이 열린다` → CSS와 JavaScript를 포함한 단일 `index.html`을 브라우저에서 직접 실행하는 것으로 구체화했다.

> **후속 미션 준비 메모:** 이번 제출물은 `기획서.md` 파일 1개이며, HTML 구현은 다음 미션에서 진행한다. 실제 경험 5개의 상세 내용은 HTML 제작 전 본인이 준비한다.
