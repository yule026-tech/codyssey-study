AI와 함께 HTML 페이지 기획서 작성하기

1. 미션 소개
우리가 브라우저에서 보는 웹 페이지의 기본 구조는 HTML이라는 언어로 작성됩니다. 따라서 HTML만으로도 관심 있는 주제를 소개하는 페이지나 자주 참고하는 학습 자료를 모은 페이지를 만들 수 있습니다.

이번에는 AI와 함께 직접 활용할 HTML 페이지를 제작해 봅니다. AI에게 제작을 요청하려면 어떤 페이지를 원하는지 구체적으로 설명해야 합니다. 예를 들어 '자료를 모아 보는 페이지를 만들어 줘'라는 요청만으로는 어떤 자료를 포함하고 어떤 순서로 보여 줄지 알기 어렵습니다. HTML 페이지를 기획할 때부터 방문자가 가장 먼저 확인할 내용과 필요한 기능을 구체적으로 정해 전달하면, AI가 구현해야 할 범위도 명확해집니다.

구현하지 않을 기능과 결과를 확인할 기준도 미리 정해야 합니다. 자료를 정리하고 열람하는 것이 목적이라면 로그인이나 회원 관리는 제외할 수 있습니다. '자료 제목을 선택하면 해당 링크가 열린다'처럼 기대하는 동작을 정해 두면, 완성된 페이지가 요청에 맞게 구현되었는지도 직접 확인할 수 있습니다. 기획서는 이러한 선택을 정리하여 AI에게 지시하고, 결과를 검토할 때 활용하는 문서입니다.

이번 미션에서는 AI의 질문에 답하며 대상 사용자, 사용 목적, 화면 구성과 동작을 구체화합니다. 필요한 기능과 제외할 기능, 완료 기준을 기획서로 정리하고, 다음 미션인 '두 AI로 HTML 만들고 테스트하기'와 '테스트하며 고치고 사용자 피드백 반영하기'에서 활용합니다.

2. 최종 결과물
다음 내용을 포함한 기획서.md 파일 1개를 제출한다. (첨부된 기획서 양식을 활용할 수 있다.)

기본 항목 5개: 대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 완료 기준
필수 기능과 추가 기능
한계 및 비목표 3가지
검증 방법 1가지
사용한 AI 서비스와 모델 이름
3. 과제 목표
이 과제를 마친 후, 학습자는 다음을 수행할 수 있어야 한다.

제작할 페이지의 목적과 기능을 기획서로 정리하고, 확인 가능한 완료 기준을 작성할 수 있다.
AI가 작성한 기획서를 검토하고 의도와 다른 내용을 수정할 수 있다.
필수 기능과 추가 기능을 구분할 수 있다.
구현 범위에서 제외할 기능과 페이지의 한계를 정리하고, 결과의 정확성을 확인할 검증 방법을 정할 수 있다.
동료의 기획서를 읽고 근거를 제시하여 평가할 수 있다.
4. 기능 요구 사항
다음 요구사항을 모두 만족해야 한다.

AI와의 질의응답을 통한 기획서 작성
AI가 먼저 질문하도록 요청하고, 질문에 답하며 대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 완료 기준을 구체화한다.
정리한 내용을 기획서.md 파일로 저장한다. AI가 작성한 내용 중 의도와 다른 부분은 직접 수정하고, 사용한 AI 서비스와 모델 이름을 기록한다.
완료 기준 정의
페이지의 완성 여부를 판단할 수 있도록, 특정 행동에 따른 기대 결과를 작성한다. 예를 들어 '사용하기 편하다' 대신 '인원수를 입력하고 계산 버튼을 누르면 1인당 금액이 표시된다'로 작성한다.
'다른 파일이나 로그인 없이 열린다'처럼 반드시 충족해야 할 조건도 포함한다.
필수 기능과 추가 기능 구분
페이지의 목적을 달성하는 데 필요한 기능을 우선 정하고, 이후 구현할 기능은 '추가 기능'으로 분류한다.
로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 이번 구현에서 제외하는 것을 권장한다. 필요한 경우 추가 기능으로 분류한다.
한계 및 비목표와 검증 방법 명시
페이지의 한계나 이번 구현 범위에서 제외할 기능을 합해 3가지 작성한다. 예: '연습 문제는 다섯 종류만 제공한다', '사용 기록 저장 기능은 구현하지 않는다'.
페이지에 표시된 내용이나 수치의 정확성을 확인할 검증 방법 1가지를 작성한다. 비교 대상과 절차를 명시한다. 예: '총금액을 인원수로 직접 나눈 값과 페이지에 표시된 1인당 금액을 비교한다'.
5. 보너스 과제 (선택)
AI에게 기획서에서 모호하거나 여러 의미로 해석될 수 있는 표현을 검토하도록 요청하고, 필요한 내용을 구체화한다.
동료에게 기획서를 보여 주고, 예상하는 화면과 사용 흐름이 기획 의도와 일치하는지 확인한다.
AI와 함께 완료 기준의 확인 방법을 검토하고, 실제로 테스트하기 어려운 기준을 보완한다.

7. 제약 사항
제출물은 기획서.md 파일 1개로 한정한다. HTML 구현은 후속 미션에서 진행한다.
로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 포함하지 않는 것을 권장한다. 필요한 경우 기획서의 추가 기능에 기록하고, 이번 HTML은 해당 기능 없이도 열리고 동작하도록 기획한다.
사진·글·글꼴·라이브러리 등 외부 자료를 활용할 계획이라면 '필요한 자료'에 출처와 사용 권한을 명시한다. 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입하도록 기획한다.
AI를 자유롭게 활용하되, 완료 기준·한계 및 비목표·검증 방법이 기획 의도에 부합하는지는 직접 검토한다.
