# My Career Archive — 취업 준비용 커리어 아카이브

## 대상 사용자

- 취업을 준비하며 프로젝트, 대외활동, 교육 경험을 직접 기록하는 본인.
- 노트북 및 휴대폰의 브라우저에서 활동을 확인하고 자기소개서·면접 준비에 활용하는 사용자.

## 사용 목적

- 여러 경험의 기간, 역할, 주요 활동, 성과를 한곳에 보관하고 유형별·활동명별로 찾아본다.
- 진행 중인 활동도 종료일 없이 기록하고, 긴 STAR 내용은 필요한 부분만 펼쳐 확인한다.
- 경험별 면접 질문·핵심 답변을 여러 쌍으로 관리하고 무작위 면접 연습에 사용한다.
- 다른 브라우저로 이동할 때 JSON 파일로 경험 데이터를 백업하고 복원한다.

## 화면 구성과 동작

- 상단에 `My Career Archive`와 `나의 경험을 기록하는 공간 ✨` 문구를 배치한다. 연보라·민트 계열의 부드러운 색상을 사용한다.
- `📂 경험 목록`과 `🎤 면접 연습` 메뉴로 화면을 전환한다.
- 경험 목록 상단에 **활동 타임라인**을 표시한다. 각 활동의 시작일·종료일을 바탕으로 활동별 가로 막대가 나타난다. 진행 중인 활동은 현재 날짜까지 표시하고, 막대나 활동명을 선택하면 해당 상세 화면으로 이동한다. 검색·유형 필터와 연동한다. 타임라인은 하나의 막대로 통합하지 않고 **활동별 가로 막대형**을 유지한다.
- `전체`, `프로젝트`, `대외활동`, `교육` 필터와 **활동명 검색창**을 제공한다. 입력한 검색어와 선택한 유형에 맞는 경험만 카드 및 타임라인에 표시한다.
- 경험 카드에는 활동명·유형·기간·담당 역할과 `진행 중/완료` 상태를 표시한다. 넓은 화면에서는 2열, 좁은 화면에서는 1열로 구성한다. 데이터가 없으면 빈 목록 안내를 보여주며 가상의 경험을 자동 입력하지 않는다.
- 경험 카드를 누르면 기본 정보, 주요 활동, 성과 및 배운 점, STAR(상황·과제·행동·결과), 면접 질문·답변 내용을 보여준다. 긴 서술 내용은 **접기·펼치기** 방식으로 필요한 부분만 확인한다.
- `+ 경험 추가` 또는 `수정`을 누르면 입력 양식으로 이동한다. 필수 항목은 활동명·유형·담당 역할·시작일·주요 활동·성과이며, 종료일은 **진행 중이 아닌 경우에만** 필수이다. `현재 진행 중인 활동 (종료일 미정)`을 선택하면 종료일을 입력하지 않아도 된다.
- STAR 내용과 면접 질문·답변은 선택 입력이다. 한 활동 안에 **질문·핵심 답변 세트를 여러 개** 추가·수정·삭제할 수 있다. 이전 버전의 단일 질문·답변도 계속 이용할 수 있도록 처리한다.
- 입력 누락 또는 잘못된 기간을 저장하려 하면 오류를 안내하고 반영하지 않는다. 삭제·작성 취소 시 확인 과정을 제공한다.
- `🎤 면접 연습`에서는 등록한 질문 중 하나를 무작위로 표시하며, 해당 활동 제목을 함께 보여준다. 사용자가 먼저 답변해 본 뒤 `핵심 답변 보기`로 답변을 확인하고 `다음 질문`을 누른다.
- 경험은 브라우저 `localStorage`에 저장되어 같은 환경에서 새로고침해도 유지된다. `JSON 백업`으로 파일을 다운로드하고, `JSON 가져오기`로 다른 브라우저에서 데이터를 복원할 수 있다. 가져오기 전 데이터 검사와 기존 기록 교체 확인 과정을 거친다.

## 필요한 자료

- 본인의 활동명, 유형, 활동 기간, 진행 여부, 담당 역할, 주요 활동 및 수행 업무, 성과와 배운 점.
- 선택적으로 STAR 4항목과 활동별 면접 질문·핵심 답변 여러 세트.
- 입력할 실제 경험의 예: Moodly, BlueRoom, 쉬운 고지서 AI, 코더스, 코디세이. **이 이름들은 사용자가 입력하는 실제 경험의 예시일 뿐, HTML 초기 데이터에 포함되지 않는다.**
- 활동 내용을 확인할 본인 작성 기록과 프로젝트 보고서 등. 외부 이미지·글꼴·라이브러리는 사용하지 않는다.

## 완료 기준

1. HTML 파일 1개로 페이지가 열리고, 저장된 내용이 없으면 경험 카드가 0개이며 임의의 예시 데이터가 표시되지 않는다.
2. 필수 정보를 입력해 경험을 추가하면 목록과 상세 화면에 반영된다. 필수값 누락, 잘못된 기간 입력 시 저장되지 않고 안내가 나타난다.
3. 진행 중을 선택한 활동은 종료일 없이 저장되고 카드·상세 화면에서 `진행 중`으로 표시된다. 일반 활동은 `완료`로 표시된다.
4. `프로젝트` 필터와 활동명 검색으로 해당하는 경험만 표시되며, 필터·검색을 초기화하면 전체가 다시 표시된다.
5. 활동 카드의 상세 정보에서 긴 본문을 접거나 펼칠 수 있고, 수정·삭제가 가능하다.
6. 활동별 가로 막대 타임라인에 기간이 표시되고, 활동명이나 막대를 선택하면 해당 활동 상세 보기로 이동한다.
7. 질문·답변을 2세트 이상 저장하고, 면접 연습에서 활동명과 무작위 질문을 확인하며 답변 보기로 핵심 내용을 열 수 있다.
8. JSON 백업 후 다른 브라우저에서 파일을 가져오면 활동이 복원되고, 새로고침해도 유지된다. 이 기능은 **수동 복원**이며 자동 동기화는 아니다.
9. 기존의 경험 수정·삭제, 유형별 필터, 저장 기능이 개선 뒤에도 유지된다.
10. CSS·JavaScript가 포함된 단일 HTML로 동작하며 로그인·서버·외부 API 키·인터넷 연결은 필요하지 않다.

## 추가 기능

- 향후 계정 기반 클라우드 동기화 및 여러 기기에서 자동으로 같은 데이터 확인하기.
- 향후 사용자별 면접 연습 기록·복습 현황 관리.
- 향후 경험 내용 내보내기(PDF 등) 또는 자기소개서용 출력 형식 추가.

## 한계 및 비목표

1. 사용자 계정이나 서버 데이터베이스가 없으므로 브라우저 간 **자동 동기화는 지원하지 않는다**. JSON 백업·복원은 사용자가 직접 수행하며, 브라우저 데이터 삭제 등에 대비한 백업 관리가 필요하다.
2. 입력한 경험의 사실 여부·성과·맞춤법을 자동 검증하지 않는다. 실제 내용의 정확성은 사용자가 직접 확인한다.
3. 챗봇이나 AI 면접 평가·답변 자동 생성 기능은 제공하지 않는다. 면접 연습은 사용자가 등록한 질문을 무작위로 보여주는 기능이다.

## 검증 방법

- 테스트용 활동 1건을 등록해 원본 기록과 활동명·기간·역할·주요 내용·성과를 대조한다. 진행 중 표시, 유형 필터와 검색, 상세 접기·펼치기, 수정·삭제 후 재조회, 새로고침 후 저장 여부를 확인한다. 이어 JSON 백업을 다른 브라우저로 가져와 같은 내용이 보이는지 비교하고, 질문 2세트를 등록해 면접 연습 화면에 활동명·질문·핵심 답변이 올바르게 연결되는지 확인한다. 타임라인의 막대 기간도 입력 날짜와 대조한다.
