# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT (GPT-6) / **[캡처한 이미지 파일명 입력: 예 `미션4_AI대화.png`]**
- 더한 기능과 고른 이유: **영화별 별점 평가 기능(1~5점)**을 추가했다. S·A·B·C 등급으로 영화를 분류하는 것뿐 아니라 각 영화에 대한 만족도를 별점으로 간단히 표현하고, 나중에 다시 확인할 수 있도록 하기 위해 선택했다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| `영화_기능추가.html` | 확인한 테스트 7개에서 맞지 않은 항목 없음 | **완성**. 별점 표시·선택·변경, 영화 이동 뒤 별점 유지, 영화 추가, 새로고침 뒤 저장 상태 유지, '처음으로' 초기화를 직접 확인했다. 수정 파일을 추가로 만들거나 원본으로 되돌아갈 필요가 없었다. |

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 별점 기능을 추가하면서 원래 영화 이동·추가·저장·초기화 기능까지 확인해야 하는 이유를 다른 동료의 테스트 방법과 비교해 보고 싶다.

## 최종 파일

- 완성본: `영화_기능추가.html`
- 원본 보존: `영화_원본.html` (수정하지 않음)
- 수정한 기획서: `기획서.md` (별점 기능의 완성 기준 추가)

## 직접 확인한 테스트

1. 영화 카드 아래 별점 표시 확인 — 정상
2. 기생충에 별점 4점 선택 — 정상
3. 기생충 별점을 2점으로 변경 — 정상
4. 기생충을 S등급으로 옮겨도 별점 유지 — 정상
5. 새 영화 추가 — 정상
6. 새로고침 뒤 영화 배치와 별점 유지 — 정상
7. '처음으로'를 눌렀을 때 초기 영화 8개와 미설정 별점 복귀 — 정상
