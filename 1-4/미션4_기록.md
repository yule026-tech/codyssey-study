# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT (GPT-6) / `image.png`
- 더한 기능과 고른 이유: **영화별 감상평 작성·수정·저장 기능**을 추가했다. 기존 프로그램에서는 영화를 S·A·B·C 등급으로 구분할 수 있지만, 각 영화를 보고 느낀 점이나 인상 깊었던 내용을 글로 남길 수 없었다. 영화마다 감상평을 기록하고 나중에 다시 확인할 수 있도록 이 기능을 선택했다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| `영화_기능추가.html` |없음. 감상평 작성·수정·저장 및 기존 기능 모두 정상 작동함. | 완성. 원본 파일을 보존하고 새 파일로 저장하였으며, 모든 완성 기준을 충족하여 최종 완성본으로 결정함. |

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI가 감상평 기능을 추가한 뒤 기존 영화 이동·추가·저장·초기화 기능까지 다시 확인해야 하는 이유와, 문제가 발생했을 때 수정 요청과 원본 복귀 중 어떤 방법을 선택해야 할지 동료의 방법과 비교해 보고 싶다.

## 최종 제출 전 확인 사항

- 원본 파일: `영화_원본.html` (수정하지 않고 보존)
- 수정한 기획서: `기획서.md` (감상평 기능의 완성 기준 추가)
- 받은 파일: `영화_기능추가.html`
- 최종 완성본: 테스트 후 확정
- 캡처: 실제 대화 화면 캡처 파일명을 위에 기입

## 기능 테스트 기록

- [O] 영화 카드를 선택하면 감상평 입력창이 나타나는가?
- [O] 감상평을 작성하고 저장하면 다시 확인할 수 있는가?
- [O] 감상평을 수정하여 다시 저장할 수 있는가?
- [O] 영화를 다른 등급으로 옮겨도 감상평이 유지되는가?
- [O] 같은 브라우저에서 파일을 다시 열어도 감상평과 영화 배치가 유지되는가?
- [O] 새 영화 추가, 카드 선택 이동, 드래그 이동 기능이 정상 작동하는가?
- [O] 빈 제목이 추가되지 않고 좁은 화면에서도 사용 가능한가?
- [O] '처음으로'를 누르면 영화 8개가 미분류로 돌아가고 감상평도 초기화되는가?

> 모든 기준을 확인한 뒤 문제없으면 표의 '맞지 않은 완성 기준'을 '없음'으로, 조치를 '완성'으로 변경한다. 문제가 나타나면 실제 증상과 수정·원본 복귀 과정을 기록한다.
