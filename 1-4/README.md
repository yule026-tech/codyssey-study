1. 미션 소개
잘 동작하는 영화 티어리스트에 내가 고른 기능 하나를 AI로 더합니다. 예를 들어 칸마다 영화 개수 보여 주기, 제목으로 영화 찾기, 카드에 한 줄 메모 달기, 칸 이름 바꾸기 같은 기능입니다. AI에게 기능을 더해 달라고 하면, 새 기능은 되는데 원래 되던 기능이 망가지는 경우가 있습니다. 새 기능과 함께 원래 기능도 직접 확인하고, 망가졌으면 원래 파일로 돌아가 다시 요청합니다.

미션을 마친 뒤 동료와 결과물과 작업 과정을 비교합니다. 사용한 AI 이름(모델 이름이 보이면 함께)과 대화  요청·답변이 보이는 주요 화면 캡처를 미션 중에 남겨 주세요.

2. 진행 순서
1) 원본 파일을 써 봅니다. 영화_원본.html을 열고 기획서.md의 완성 기준대로 되는지 하나씩 해 봅니다. 이 파일은 고치지 않고 그대로 둡니다.

2) 더할 기능을 정합니다. 기능을 하나 고르고, 무엇을 했을 때 어떻게 되면 성공인지 기획서.md의 완성 기준 끝에 덧붙입니다.

3) AI에게 기능을 더해 달라고 합니다. 영화_원본.html과 기획서.md를 첨부하거나 붙여 넣고 요청합니다.

영화 티어리스트에 [더할 기능]을 추가해 줘.
첨부한 기획서의 완성 기준이 모두 맞아야 해. 원래 기능은 바꾸지 마.
수정한 HTML 전체를 줘.

4) 받은 파일을 완성 기준으로 확인합니다. 받은 파일은 원본을 덮어쓰지 않고 영화_기능추가.html로 저장합니다. 열어서 완성 기준을 처음부터 하나씩 해 봅니다. 새 기능이 틀리면 본 대로 말해 고칩니다. 고친 파일도 영화_기능추가_수정1.html처럼 새 이름으로 저장하고 다시 확인합니다. 모두 맞으면 완성입니다.

5) 원래 기능이 망가졌으면 원래 파일로 돌아갑니다. 망가진 파일을 계속 고쳐 달라고 하지 않습니다. 영화_원본.html을 가지고 새 대화에서 다시 요청합니다. 원래 기능이 망가지지 않았다면 이 단계는 건너뜁니다.
